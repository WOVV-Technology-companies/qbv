# qbv

一个无外部依赖的离线网页钱包，用于在断网环境中加密记录资产、账户/地址、交易备忘，并通过助记词离线派生多网络地址与消息签名。

## 功能

- 纯静态网页：直接打开 `index.html` 即可使用，不需要构建步骤。
- 本地加密：使用浏览器 Web Crypto API，通过 PBKDF2-SHA256 派生密钥并用 AES-256-GCM 加密钱包数据。
- 离线优先：界面会提示当前网络状态；通过本地文件打开时无需网络，通过 Web 服务访问时会注册 Service Worker 缓存静态资源。
- 备份迁移：支持导出/导入加密 JSON 备份，导入后仍需要原主密码解锁。
- 助记词派生：输入英文 BIP39 助记词和可选 passphrase，可生成 EVM 网络、BTC、LTC、DOGE、DASH 的地址、公钥、私钥和 WIF。
- 离线签名：支持 EVM `personal_sign` 和 Bitcoin 风格消息摘要签名；签名只在本地完成，不广播交易。

## 使用方式

1. 将仓库复制到一台可信设备。
2. 断开网络后打开 `index.html`。
3. 如需记录数据，创建钱包并设置至少 10 个字符的主密码。
4. 可添加资产、账户/地址和交易备忘，也可用助记词派生工具生成地址后加入钱包记录。
5. 如需签名，在离线签名区域填入私钥和消息，复制生成的签名结果。
6. 定期导出加密备份，并将备份文件保存到多个安全介质。

## 支持的派生网络

- Ethereum、BNB Smart Chain、Polygon、Base、Arbitrum One、Optimism、Avalanche C-Chain：`m/44'/60'/0'/0/{index}`。
- Bitcoin：`m/84'/0'/0'/0/{index}`，生成原生 SegWit `bc1q...` 地址。
- Litecoin：`m/84'/2'/0'/0/{index}`，生成原生 SegWit `ltc1q...` 地址。
- Dogecoin：`m/44'/3'/0'/0/{index}`，生成 P2PKH 地址和 WIF。
- Dash：`m/44'/5'/0'/0/{index}`，生成 P2PKH 地址和 WIF。

## 安全提示

- 该项目不会联网同步，也不会替你广播链上交易。
- 主密码、助记词、passphrase、私钥无法找回；丢失这些信息或加密备份会导致数据不可恢复。
- 请不要在不可信或已感染恶意软件的浏览器/系统上输入敏感信息。
- 输入助记词或私钥前，请确认设备已断网，并优先使用专用硬件钱包管理大额资产。
- 当前签名功能是消息签名，不是链上交易构造或交易广播工具。
